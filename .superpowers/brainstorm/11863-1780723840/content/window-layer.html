关键实现细节

窗口层级 使用 .screenSaver 级别，确保覆盖所有窗口（包括全屏应用）。设置 isOpaque = false + backgroundColor = .clear 保持透明
毛玻璃 NSVisualEffectView 作为 contentView 的第一层子视图。.behindWindow blending 让它采样桌面壁纸。如果用户开启「降低透明度」，回退为纯色背景
全局热键 CGEventTap 监听 flagsChanged 事件。首次使用需引导用户在「系统设置 → 隐私 → 辅助功能」中授权。提供 fallback：菜单栏图标右键菜单
多显示器 在当前活跃屏幕（鼠标所在屏幕）上显示。监听 NSApplication.didChangeScreenParametersNotification 处理显示器热插拔
关闭行为 ESC 键关闭 · 点击空白区域关闭 · 点击应用启动后关闭 · 热键再次按下切换
