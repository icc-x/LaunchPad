│ 匹配规则:                    │
│ ┌──────────────────────────┐ │

│ │    "sa" → Safari > Tessa │ │
│ │                          │ │
│ │ 3. 同时匹配 bundle_id    │ │
│ │    "com.apple" → ...     │ │
│ │                          │ │
│ │ 4. 搜索范围:             │ │
│ │    • app title           │ │
│ │    • group title         │ │
│ │    • bundle identifier   │ │
│ └──────────────────────────┘ │
│                              │
│ 性能:                        │
│ • debounce 100ms             │
│ • 后台线程搜索               │
│ • 搜索结果缓存 (LRU 50条)   │
│ • 空查询立即恢复完整网格     │
└──────────────────────────────┘

匹配算法伪代码:
func match(item, query) → Score:
  title = item.title.lowercased()
  q = query.lowercased()

  if title.hasPrefix(q) → score 100
  if title.contains(q)  → score 50
  if title.words.contains(where:
    { $0.hasPrefix(q) }) → score 75
  if bundleId.contains(q) → score 25
  return 0  // 不匹配

关键行为细节

输入捕获 LaunchPad 可见时，任何键盘输入自动进入搜索（无需先聚焦搜索栏）。使用 keyDown 事件拦截，字符追加到 query
原位过滤 搜索结果替换当前页内容（非覆盖层）。匹配项重新布局到网格中，支持多页。页码点隐藏，显示结果计数
防抖策略 100ms debounce，避免每个字符都触发全量搜索。Backspace 立即响应不防抖
清空搜索 按 ✕ 按钮 / ESC（搜索非空时）/ 全选+Delete。清空后恢复原始页面布局和页码
搜索中的交互 搜索结果中可以点击启动应用（启动后清空搜索并关闭）。不允许拖拽排序
