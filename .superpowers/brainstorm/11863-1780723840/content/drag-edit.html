拖拽实现方案

A

NSCollectionView 内置拖拽（推荐）

利用 NSCollectionView 的 canDragItems / pasteboardWriterForItemAt / validateDrop / acceptDrop API。框架自动处理 drop 位置检测和动画。

优点：系统级拖拽支持、拖拽预览自动生成、与 Finder 等应用互通
缺点：跨页拖拽需要额外处理边缘检测和自动翻页

B

完全自定义拖拽

用 mouseDown / mouseDragged / mouseUp 手动实现。创建一个独立的 TileDragWindow 跟随鼠标（和原版一样）。其他图标用动画让位。

优点：完全控制视觉效果，与原版行为一致
缺点：需要手动实现 hit testing、drop 检测、动画，工作量大

抖动动画实现

旋转动画 CABasicAnimation 作用于 transform.rotation.z。角度 ±2°~3°，duration 0.12~0.15s，autoreverses，每个 cell 随机延迟 0~0.1s 避免同步
进入抖动 长按 0.5s 触发（距离阈值 < 10px 才算长按，否则进入拖拽）。进入时所有图标同时开始抖动 + 淡入 ✕ 按钮
退出抖动 ESC 或点击空白区域。图标渐停旋转 + ✕ 淡出。如果位置有变动，触发保存布局
Reduce Motion 监听无障碍设置，开启时抖动改为图标轻微缩放脉冲（scale 1.0→1.05→1.0），✕ 按钮直接显示无动画

跨页拖拽

边缘检测 拖拽图标进入屏幕左/右边缘 40px 区域时，启动 1.5s 倒计时。倒计时结束后自动翻页，图标跟随到新页面
取消翻页 在倒计时内拖离边缘区域则取消。鼠标移动角度检测（必须朝边缘方向移动才触发）
翻页动画 翻页期间拖拽预览窗口保持跟随鼠标。新页面加载后，图标在新页面的对应位置显示
