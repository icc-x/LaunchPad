核心模块边界

App Layer 窗口管理、全局热键、主控制器协调。每个类职责单一，通过 delegate/通知通信
View Layer 纯 UI 组件，不含业务逻辑。CollectionView cell、搜索栏、页码指示器各自独立
Service Layer 应用扫描、图标缓存、拖拽状态机。可独立测试，不依赖 UI
Data Layer SQLite 持久化、数据模型。所有数据操作通过 StorageManager 统一入口
